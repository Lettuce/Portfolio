# Images

Drop your image files in this folder using these exact names, and the site will pick them up automatically (no code changes needed):

| Filename | Used in | Suggested size/ratio |
|---|---|---|
| `profile.jpg` | Hero section headshot | Square, at least 400x400px |
| `project-learning-engine.jpg` | Learning Engine project card | 16:9, at least 800x450px |
| `project-rag-qa.jpg` | RAG Document Q&A project card | 16:9, at least 800x450px |
| `project-leetcode.jpg` | LeetCode Grind 75 project card | 16:9, at least 800x450px |
| `ar-sandbox.jpg` | Library Scholar Intern / AR sandbox experience item | 16:9, at least 800x450px |

Until a file is added, that slot simply stays empty (a themed gradient placeholder shows instead) — nothing breaks.
